# English Coach – מדברים אנגלית בביטחון 🗣️

אפליקציית ווב ללימוד אנגלית לדוברי עברית. הדגש הוא על **דיבור והבנת הנשמע**, לצד אוצר מילים אישי. הממשק כולו בעברית מימין לשמאל, מותאם קודם כול לטלפון.

**הזרימה המלאה:** הרשמה → אבחון אדפטיבי → מסלול אישי → שיעור (מילים, האזנה, הבנה, דיבור) → משוב → שמירת התקדמות → שיחה עם מורה AI → אבן דרך → השלב הבא.

## הפעלה

דרוש Node.js 22.5 ומעלה (משתמשים במסד הנתונים SQLite המובנה ב-Node, בלי תלויות שצריך לקמפל).

```bash
npm install
npm run build        # בניית הממשק
npm start            # השרת עולה בכתובת http://localhost:3000
```

פיתוח: מריצים `npm start` ובמקביל `npx vite`. הממשק זמין ב-http://localhost:5173 עם הפניית `/api` לשרת.
בדיקות: `npm test`.

כדי להפעיל את המורה ואת הקול האיכותי, מעתיקים את `.env.example` לקובץ `.env` וממלאים מפתחות. `npm start` טוען את הקובץ אוטומטית.

## גרסת ניסיון בדפדפן (בלי שרת)

`npm run build:trial` בונה קובץ HTML יחיד (`artifact/dist/english-coach.html`) שמריץ את כל קוד השרת בתוך הדפדפן: SQLite דרך sql.js, נתונים שנשמרים ב-localStorage, ומורה AI דרך Claude של מי שצופה בעמוד (כשהעמוד מוצג ב-claude.ai).

המגבלות: בגרסה הזו אין מיקרופון, ולכן עונים בהקלדה. בנוסף, ההתקדמות נשמרת רק בדפדפן שבו עבדת.

## טכנולוגיות

| שכבה | בחירה | למה |
|---|---|---|
| שרת | Node.js + Express | פשוט, מוכר, וכל המפתחות נשארים בשרת |
| מסד נתונים | SQLite (`node:sqlite`) | קובץ אחד, בלי שרת נוסף. אפשר להחליף ל-Postgres בהמשך |
| אימות | אימייל וסיסמה, גיבוב scrypt, עוגיית סשן httpOnly ו-SameSite, הגנת CSRF, הגבלת ניסיונות, איפוס סיסמה בטוקן חד-פעמי | תקן מקובל ומאובטח |
| ממשק | React + Vite | |
| מורה AI | Claude (Anthropic) עם פלט JSON מובנה | שיחה טבעית ומשוב פדגוגי בעברית |
| קול | OpenAI TTS ותמלול, ואם אין מפתח: Web Speech API של הדפדפן | עובד גם בלי חשבון בתשלום |

## מה עובד בפועל

- **חשבונות:** הרשמה, כניסה, יציאה, שם משתמש, איפוס סיסמה, מחיקת חשבון. כל שאילתה מסוננת לפי המשתמש המחובר, ויש בדיקות אוטומטיות שמוודאות שמשתמש אחד לא רואה ולא משנה נתונים של אחר.
- **אבחון ראשוני:**
  - שאלות על מטרות, תחומי עניין וזמן יומי.
  - הבנת הנשמע ואוצר מילים בשיטה אדפטיבית: תשובה נכונה מעלה את רמת השאלה הבאה, שגויה מורידה.
  - 3 משימות דיבור בקושי עולה.
  - התוצאה היא רמת CEFR עם הסבר בעברית, מוצגת במפורש כהערכה לימודית ולא כמבחן הסמכה.
  - אפשר לדלג ולהתחיל מ-A1.
- **מסלול:**
  - 4 שלבים (A1 עד B2), 8 יחידות ו-8 שיעורים מלאים. לכל יחידה מוגדרת יכולת מעשית.
  - השיעורים נפתחים לפי הסדר, ושלבים מתחת לרמה שאובחנה פתוחים לחזרה.
  - כל שלב מסתיים ב**אבן דרך**: שיחה מלאה בקול שבה צריך להשיג את מטרת התרחיש. בלעדיה השלב הבא לא נפתח.
- **שיעור:**
  - ביטויים בהקשר עם השמעה.
  - האזנה לשיחה בלי טקסט, עם השמעה חוזרת והאטה.
  - שאלות הבנה עם הסבר בעברית.
  - תמלול ותרגום שאפשר לחשוף אחרי השאלות.
  - סיכום בעל-פה של מה שנשמע.
  - שימוש בביטויים במשפט חדש בקול.
  - 3 משימות דיבור עם משוב.
  - **מעבר שיעור דורש הוכחת יכולת:** לפחות 2 תשובות הבנה נכונות, 2 משימות דיבור שהושגו, ביטוי אחד ששומש נכון, ולפחות משימה אחת שבוצעה בקול ולא בהקלדה.
- **שיחה עם המורה:** 8 תרחישים: היכרות, בית קפה, מסעדה, קניות, שיחת חולין, מלון, ישיבת עבודה ושיחה חופשית.
  - כפתור מיקרופון גדול, חיווי הקלטה עם מד עוצמה, עצירה, והשמעה חוזרת של ההקלטה שלכם.
  - המורה עונה בקול. אפשר להציג או להסתיר תמלול ותרגום.
  - כפתורי עזרה: רמז, הסבר בעברית, דיבור איטי יותר, ניסוח פשוט יותר.
  - שני מצבי משוב: "תרגול מודרך" (משוב אחרי כל תשובה) או "שיחה זורמת" (משוב מרוכז בסוף).
  - אפשר להקל או להקשות את רמת השיחה.
  - כפתור לשמירת ביטויים שעלו בשיחה למאגר האישי.
- **משוב:**
  - מציג מה אמרתם, ועד 2 תיקונים בלבד.
  - מבחין בין "טעות לתיקון" לבין "אפשר לשפר" (ניסוח תקין שאפשר להפוך לטבעי יותר).
  - הסבר בעברית, ניסוח טבעי באנגלית עם השמעה, וכפתור "לומר שוב".
- **אוצר מילים:**
  - מאגר אישי שמתמלא מהשיעורים, מהשיחות ומחבילות לפי תחומי עניין (8 נושאים).
  - חזרה מרווחת בשיטת Leitner.
  - כל חזרה כוללת זיהוי של המשמעות **וגם** שימוש בביטוי במשפט חדש. ביטוי נחשב "שלי" רק כשעבר את שניהם כמה פעמים.
- **מסך התקדמות:**
  - מאיפה התחלתי, איפה אני והצעד הבא.
  - נתונים נפרדים לדיבור (דקות הקלטה בפועל, משימות ושיחות), להאזנה (תשובות נכונות) ולמילים.
  - גרף 14 ימים, רצף ימים, יכולות שנרכשו ונושאים לחיזוק.
  - אבחוני ביניים לאורך זמן.
  - אין אחוזי שליטה וגם אין ציון הגייה.
- **חוויית שימוש:**
  - מצבי טעינה ושגיאה ברורים.
  - טיפול במיקרופון חסום, חסר או תפוס, ובמצב שבו לא נשמעו מילים.
  - התראה כשאין חיבור לאינטרנט, וזמן קצוב לבקשות כשהחיבור חלש.
  - מצב הקלדה שמסומן בבירור כ"לא תרגול דיבור".
  - מצב כהה, `prefers-reduced-motion`, ופוקוס נגיש במקלדת.
- **פרטיות:**
  - בקשת הרשאת המיקרופון מגיעה רק בלחיצה הראשונה, ולפניה מסך שמסביר איך משתמשים בהקלטה.
  - **הקלטות לא נשמרות:** הן נשארות בזיכרון הדפדפן להשמעה חוזרת. כשמשתמשים בתמלול בשרת, האודיו נשלח לתמלול ולא נשמר.

## מצב הדגמה (בלי מפתחות)

אפשר להריץ את האפליקציה מקצה לקצה בלי שום חשבון בתשלום. במצב הזה:

- **המורה:** עוקב אחרי תסריט כתוב מראש לכל תרחיש. הוא מתקדם רק כשהתשובה רלוונטית, ואחרת מבקש שוב.
- **המשוב וההערכה:** מבוססים על כללים פשוטים (מילות מפתח ושגיאות נפוצות), **לא על AI**.
- **הערכת הדיבור באבחון:** הערכה גסה בלבד.
- **הקול:** של הדפדפן.

כל אחד מהמצבים האלה מסומן בבירור בממשק: באנר עליון, תגית "משוב הדגמה", ומסך "שירותים מחוברים" בהגדרות.

## שירותים חיצוניים ועלויות

| שירות | נדרש? | עלות | מה משפיע על העלות |
|---|---|---|---|
| **Anthropic (Claude)**: מורה, משוב, הערכת דיבור | מומלץ מאוד | תשלום לפי טוקנים. ברירת המחדל Claude Opus 5.5: ‎$4 לכל מיליון טוקני קלט ו-$20 לכל מיליון טוקני פלט, כלומר בערך 1–2 סנט לכל תור בשיחה. עם `CLAUDE_MODEL=claude-haiku-5-5` ‏($0.10 / $0.50) העלות נמוכה פי עשרות | מספר התורות בשיחות ובמשימות. האורך גדל עם היסטוריית השיחה (עד 24 תורות אחרונות) |
| **OpenAI**: הקראה ותמלול | אופציונלי | תשלום לפי תווים שמוקראים ולפי דקות אודיו. ההקראות נשמרות במטמון בזיכרון השרת | כמות האודיו. בלי המפתח משתמשים בדפדפן בחינם |
| **SMTP**: מיילים לאיפוס סיסמה | בייצור | לרוב חינם בהיקף קטן (למשל Brevo, Mailgun, SES) | |
| זיהוי דיבור בדפדפן | חינם | | נתמך ב-Chrome, Edge ו-Safari. ב-Chrome האודיו עובר לשרתי Google. לא נתמך ב-Firefox, ושם עוברים להקלדה או מגדירים תמלול בשרת |

**הערכת הגייה:** לא מופעלת, ולכן לא מוצג שום ציון הגייה. אסור להסיק ציון כזה מתמלול. כדי להוסיף אותה, צריך שירות שמנתח את האודיו עצמו, למשל Azure Speech Pronunciation Assessment. המטרה היא מובנות וביטחון, לא מחיקת המבטא.

## מבנה הקוד

```
server/
  index.js          נתיבי API: אבחון, מסלול, שיעורים, מורה, אוצר מילים, התקדמות, קול
  auth.js           הרשמה, כניסה, סשנים, איפוס סיסמה
  db.js             סכמת SQLite
  ai.js             Claude עם סכמות JSON, וגם מצב הדגמה
  speech.js         TTS/STT אופציונלי (OpenAI)
  content/          תוכן לימודי: lessons, scenarios, diagnostic, vocabPacks
client/src/
  components/Recorder.jsx   רכיב הדיבור המרכזי
  lib/speech.js             הקראה, הקלטה וזיהוי דיבור
  pages/                    המסכים
test/api.test.js            בדיקות מקצה לקצה של ה-API
```

**הוספת תוכן:**
- שיעור חדש: מוסיפים אובייקט ל-`LESSONS` ומשייכים אותו ליחידה ב-`STAGES` (בקובץ `server/content/lessons.js`).
- תרחיש שיחה חדש: מוסיפים ל-`server/content/scenarios.js`.

## מה עדיין דורש פיתוח

- **תוכן:** כרגע 8 שיעורים, שיעור אחד לכל יחידה. צריך להרחיב לכמה שיעורים ליחידה ולהוסיף שלב C1. כדאי גם קטעי שמע מוקלטים של דוברים אמיתיים במקום הקראה, עם מבטאים מגוונים.
- **הערכת הגייה מבוססת אודיו:** ראו למעלה.
- **אימות בצד השרת של משימות דיבור:** השרת בודק בעצמו את תשובות ההבנה, אבל תוצאת "הושג" של משימת דיבור מגיעה מהלקוח. אפשר לחזק זאת בעזרת אסימון חתום שהשרת מנפיק בכל הערכה.
- **הסתגלות עמוקה יותר:** כרגע קצב ההשמעה נקבע לפי הרמה, נושאים חלשים חוזרים, ויש בחירת רמה בשיחה. השלב הבא הוא בחירה אוטומטית של רמת השיחה לפי הביצועים, ויצירת תרגילי חזרה ממוקדים מנקודות החולשה.
- **שימוש גדל ממשק באנגלית בהדרגה:** כרגע מרמה B1 השאלות מוצגות באנגלית והעברית משנית. אפשר להרחיב את זה לכל הממשק.
- **תשתית לייצור:**
  - Postgres במקום SQLite אם יש כמה שרתים.
  - הגבלת קצב משותפת, למשל עם Redis.
  - ניטור, ו-HTTPS (חובה בשביל המיקרופון בדפדפן, למעט `localhost`).
- PWA או התקנה למסך הבית, ותזכורות יומיות.
